# Frontdesk

Turn your company docs into a support chatbot — available as a playground inside the app and as an embeddable widget for your customers' sites.

A clickable prototype. No backend: all data lives in `src/mock/`.

## Run

```
npm install
npm run dev
```

Open `/kitchen-sink` — layer 1 of the build is the design system showcase.

## Fonts

Download and drop into `public/fonts/`:

- `Satoshi-Regular.woff2`, `Satoshi-Medium.woff2` — fontshare.com/fonts/satoshi
- `GeistMono-Regular.woff2` — vercel.com/font

Until they are added, the interface falls back to system faces.
